A complete battery calculator WordPress theme — 12 calculators, guides, FAQ, and a homepage load estimator.

== Description ==

Batterysizing recreates the BatterySizing.xyz calculator platform as an installable WordPress theme.

* 12 interactive calculators (runtime, capacity, backup, bank, solar, UPS, 12V, 24V/48V, LiFePO4, Ah↔Wh, all-in-one)
* Homepage appliance load estimator with live SVG chart
* What-if runtime comparison across battery presets
* 7 educational guides + FAQ, About, Contact, Privacy, Terms
* One-click demo import: Appearance → Batterysizing Setup

Activate the theme, then open Appearance → Batterysizing Setup and click Import. Pages, menus and the static front page are created for you.
