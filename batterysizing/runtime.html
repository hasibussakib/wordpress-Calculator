      What if the load changes?

      Same battery, different watts. Runtime falls as the load rises — this is the relationship a single number hides.

      Theoretical vs practical

      Theoretical / label—V × Ah ÷ load, as if you could use every watt-hour.
      Estimated practical—After DoD, reserve, inverter losses, and Peukert on lead-acid.

      This is an estimate, not a prediction. Manufacturer limits always win.

      Worked example

      A 12V 100Ah flooded lead-acid battery running a 100W load through an 85% inverter, stopped at 50% depth of discharge.

      1. Nominal energy = 12 × 100 = 1,200 Wh
      2. Usable energy = 1,200 × 50% = 600 Wh
      3. After the inverter = 600 × 85% = 510 Wh
      4. Estimated runtime = 510 ÷ 100 = 5.1 hours (5h 06m)

      Need 8 hours instead? Target runtime reverses the same arithmetic: required Ah ≈ 157 Ah → next common size 180 Ah. Click Load example to drop these numbers into the calculator.
